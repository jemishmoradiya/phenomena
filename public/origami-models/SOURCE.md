# Origami model provenance

The baked crane, butterfly, lotus, kabuto, pigeon, mouse, masu box, owl, and
sailboat geometry sequences in this directory are derived from the corresponding playbooks in
[`georgiee/origami`](https://github.com/georgiee/origami).

Original engine and playbooks:

- Copyright (c) 2017 Georgios Kaleadis and contributors
- License: MIT
- Source models: `crane.ori`, `butterfly.ori`, `lily.ori`, `kabuto.ori`,
  `pigeon.ori`, `mouse.ori`, `masubox.ori`, `owl.ori`, and `boat.ori`

The geometry was baked into static JSON frames for compatibility with the
current Three.js renderer. The original license is reproduced in `LICENSE.txt`.
